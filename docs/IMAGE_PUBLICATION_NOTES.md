# v3.0.0 real screenshot release notes / Gerçek görsel yayın notları

This documentation refresh adds **23 user-captured PNG screenshots** (`01`–`22` and `22b`) to `docs/screenshots/final/`, a full gallery, bilingual README highlights, a newly designed **22-slide Turkish illustrated PowerPoint/PDF**, and a **10-page illustrated technical report**. No mathematical algorithms or application APIs are changed.

## Distinguish the image types

- `12-dimensional-setup.png`: deliberately cropped configuration panel, not a fullscreen view.
- `17-job-history.png`: cropped event-history detail.
- `15-job-queue-running.png`: actual progress is visible in the captured run.
- `22-mobile-responsive.png` and `22b-mobile-content.png`: mobile navigation and content, respectively.
- `14-dimensional-vectors.png`: the 2D plot is an `(x1, x2)` projection of a real D-vector.

## Public publication review / Herkese açık yayın kontrolü

Review every screenshot for job/archive identifiers and potentially private local experiment details; the assistant did not publish these images to any public repository. All images remain exactly user-supplied apart from **non-destructive presentation crops** used within PPTX/PDF.

GitHub repository publication, CI run results, contributor permissions and an open-source license remain separate owner decisions.
